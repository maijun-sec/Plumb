## 1. 口径

### 1.1 分母：为什么用「逻辑行」而不是审计总报告的 `checked`

审计的 `## A. Coverage ledger` 节里，**一个物理行不一定是一个构念**：

| 现象 | 位置 | 影响 |
|---|---|---|
| 一行里塞了**两行构念**（拼写里带 `\|`，未被转义） | `08-typescript.md:285`/`:298`/`:302` | 朴素切列会把状态列读错位 |
| **丢了换行**，三行焊成一行 | `06-csharp.md:110` | C# 的物理行数比逻辑行数少 **2** |
| **丢了换行**，表格行与 `###` 标题焊成一行 | `02-kotlin.md:63` | Kotlin A.1 的最后一行被吞进标题 |

⇒ 本方案的切列器（`D:\work\tmp\mdtable.py`）按 markdown 规则处理（代码跨度内的 `\|` 是字面量、`\|\|` 是行边界、标题被单独切出），得到每个语言面的**逻辑行数**。

**与官方 `checked` 的 25 行差值，逐条来源**：

| 来源 | 行数 | 说明 |
|---|---:|---|
| 审计标 `N/A` | 15 | Java 表达式 8 + ArkTS 4 + Scala 3 —— 该构念不在该面 / 本语言里不存在 |
| 审计标 `UNCLEAR` | 3 | Java 语句 1 + Scala 2 —— 审计自己没判定 |
| C# 的焊接行 | 2 | 物理 160 行 vs 逻辑 162 行 |
| 跨面引用行 | 4 | Java 表达式面 4 行标「（语句面，已记）」 |
| 通用安全网行 | 1 | Java 表达式面「通用『未处理表达式』安全网」——它是兜底机制，不是构念 |
| **合计** | **25** | 1472（逻辑行） − 1447（官方 `checked`）= 25 ✓ |

⇒ **本方案刻意选「逻辑行」作分母**：官方口径会把 25 行排除在外，而这 25 行**恰恰是最容易藏缺口的地方**（`N/A` 行 = 跨面引用，`NOT FOUND` 行 = 现有实现里根本没有这个构念的处理代码）。把它们排除，缺口就看不见了。
⇒ 所以本方案**逐行给了落点**：`N/A` 行的落点写「不适用（审计已判 N/A：…）」并指向另一面的完整落点；`NOT FOUND` 行的落点写「本方案新增支持」或「按编译期标记 drop」。

### 1.2 三个判定档 + 两类不需要落点的行

| 档 | 含义 | 判据（看附录的「去向」列） |
|---|---|---|
| **A 完整表达** | 构念变成真实 TAC 形状（**指令或 IR 元数据**），无语义损失 | 去向既不指向例外表、也不提 `drop` |
| **B 显式记账** | 构念**本体**完整降级，缺的**只是一个运行期才定的事实**（返回值内容 / 触发时机 / 顺序 / 注入的属性值），该缺失用 `drop` **显式记账** | 去向提到 `TacDrop` / `drop(...)` / 「级 drop」 |

⇒ **B 与 C 的分界只问一件事：构念的「本体」降下来了吗。** 降下来了、只是缺一个运行期事实 ⇒ `B`；本体就降不下来 ⇒ `C`。

## 7. 口径声明

1. **设计覆盖 ≠ 实测覆盖**。本文件证明的是：审计点名的每一个构念，在**方案**里都有落点或明确的例外理由。**方案未实现、未编译、未跑测试**，因此**不构成任何关于当前引擎行为的断言**。
2. **分母是「逻辑行」**（1472），不是官方 `checked`（1447）；差 25 行的来源已逐条列出（§1.1）。
3. **A / B / C 是语义判断**，只有「每行有落点」「去向非空」「D = 0」「编号列 == 审计行序（1015 行）或构念名逐条对齐（457 行）」「落点引用可解析（987 个）」「表格列数一致」「编码干净」是**机械可证**的。
4. **审计原表的状态词**（`KEPT` / `DEGRADED` / `DROPPED-SILENT` / `DROPPED-NOTED` / `NOT FOUND` / `N/A` / `UNCLEAR`）与**审计的行号**都被**转录**、未被改写；行号会漂，以方法名 + 代码骨架定位更稳。
5. **例外是分级的**：根因级 13 类 + 语言级 **29** 条；**没有一条是「IR 表达不了」**。
6. **B 与 C 的分界 = 「构念的本体降下来了吗」**：降下来了、只缺一个运行期事实 ⇒ `B`（显式记账）；本体就降不下来 ⇒ `C`（永久例外）。判定**可执行**（查例外表的「档」列），但「本体到底降下来没有」这一步仍是**语义判断**。
