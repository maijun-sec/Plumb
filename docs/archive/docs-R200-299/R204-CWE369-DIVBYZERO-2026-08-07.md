# R204 CWE-369 Divide-by-Zero Index + Sub-Batch — 2026-08-07

> **目标**：用 4-sub-folder batch 跑 CWE-369（之前 R200 只跑 s01 = 980 files，漏了 s02-s04 = 2092 files），并修正 isBad 分类 index
>
> **结果**：CWE-369 TP **27 → 111（+84，4.1x 增长）**，0 FP

## 1. 根因

R200 跑 CWE-369 时：
1. **index 限定在 s01 子目录**（980 files）—— s02-s04 (2092 files) 全部不在 index scope 里，coverage 把 s02-s04 finding 算作 "orphan"（=FN）
2. **Plumb batch 实际只 process 28 unique source types**（不是 38 sub-patterns × 28 sources = 1064）—— R203 batch 同样 28 限制（与 R200 相同）

R200 跑出 27 TP 的真相是：s01 内 28 source types × 1 sub-pattern (`_01.java` baseline + 部分 cross-class) = 27 fires。其他 ~600 个 bad file 都没 fire div-by-zero because：
- batch mode O(N²) cross-class dispatch OOM
- 或 DFA 不能 taint propagate 跨 sub-pattern `_22a`/`_22b` helper dispatch

## 2. 修复

### 2.1 重生成 4-sub-folder index (`_build_index2.js`)

扩展 `juliet-eval-sub.ps1` 的 index 生成逻辑到所有 4 sub-folder：

```js
const subs = ['s01', 's02', 's03', 's04'];
for (const sub of subs) {
    const subPath = path.join(cweRoot, sub);
    walk(subPath);  // recursively find all .java
}
// classify via method name regex (bad|good[12G2B1-2B2G1-2]?|action)
// followed by [ \t]*\([^)]*\)  — ensures exact method name match (NOT badSink)
```

Critical fix: regex 用 `[ \t]*\([^)]*\)` 强制 method name 后面必须立即跟 `(` —— 避免误匹配 `badSink` 之类的部分名字。

### 2.2 重跑 4 sub-folder batch (`run_r203_all.ps1` already supports sub-folder)

CWE-369 实际 4 sub-folder：s01 (980) + s02 (982) + s03 (982) + s04 (128) = 3072 files.

每个 sub-folder ~ 3-4 分钟，总共 13-15 分钟跑完。

## 6. 关键经验

1. **CWE-369 sub-folder 是 Juliet-specific** —— 一个 CWE 内不同 sub-folder 跑不同 source 类型（s01=connect_tcp/console_readLine/d..., s02=Servlet_* listen_tcp/PropertiesFile, s03=Servlet_* Property, s04=int_zero）。R200 只跑 s01 严重低估
2. **Plumb batch O(N²) 限制** — 28 unique sources 实际是 Plumb 处理 budget，不是 catalog/source 缺
3. **R182 String→numeric bridge 仍有效** — single-file `connect_tcp_divide_01.java` 100% 触发，但 batch 中 cross-file taint propagation 失败
4. **Multi sub-folder 必须重 build index** — R200 时代 `juliet-eval-sub.ps1` 只为 s01 建 index，R204 重 build 跨 4 sub-folder
