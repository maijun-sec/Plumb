## 关键经验 (R246)

1. **method call offset 含义**: offset==0 = implicit `this`, offset>0 = explicit receiver. R209 漏了 ==0 是常见疏漏
2. **traceIntoCallee 必须支持两种调用方式**: pre-existing code 经常只考虑一种
3. **name-based fallback 通用化**: `this` TacVar identity 在每个函数不同, 必须用 name 匹配
4. **single file test 必跑**: R246 single file 0 → 2 fire 立即验证 fix 有效
5. **R257 attempt 教学价值**: 把 fallback 推广到任意 key 不会自动解决 cross-class 问题, 因为 static field write 在 batch mode 下未必进 fieldMap. 0 FP 但 no-op.
