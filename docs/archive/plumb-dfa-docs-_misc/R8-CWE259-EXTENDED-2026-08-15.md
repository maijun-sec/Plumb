## What R8 added

| Sink | Pattern | Args[password] | Inline literal | toCharArray passthrough |
|------|---------|----------------|----------------|-------------------------|
| `DriverManager.getConnection/3` | CALL | args[3] | ✓ | ✓ |
| `new KerberosKey.<init>/3`      | NEW  | args[1] | ✓ | ✓ |
| `new PasswordAuthentication.<init>/2` | NEW | args[1] | ✓ | ✓ |

### 2. Inline literal detection

R6 only fired when a literal was first stored in a local via MOVE
(`String data = "7e5tc4s3"; data.toCharArray(); ... new KerberosKey(... data.toCharArray() ...)`).
R8 also fires on inline literals at the call site:

```java
// R8 inline literal (no MOVE):
Connection c = DriverManager.getConnection(
    "jdbc:hsqldb:mem:test", "sa", "7e5tc4s3");
new PasswordAuthentication("user", "7e5tc4s3".toCharArray());
```

The TAC for inline `"hardcoded-pwd".toCharArray()` is:

```
CALL sig=scope.toCharArray/0  dest=t_t1  lhs1=
    args = <STRING:hardcoded-pwd>
```

The receiver at `args[0]` is a `TacConst` STRING (not a TacVar), so
the original R6 MOVE-tracking wouldn't see it. R8 handles both:
- Receiver is a TacVar in `literalSourced` (the MOVE case)
- Receiver is a `TacConst` STRING (the inline case)

### 3. `toCharArray` / `getBytes` passthrough

R8 tracks `t = x.toCharArray()` (or `t = x.getBytes(...)`) where
`x` is a literal source. The result `t` is registered in
`derivedOfLiteral` with the original literal as the value, so
the finding can show what the password actually is.

`TacBuilder` lowers `v.toCharArray()` to:

```
CALL sig=java.lang.String.toCharArray/0  dest=t_t1  lhs1=
    args = v
```

`calleeSig` contains `.toCharArray` (or `.getBytes`); args[0] is
the receiver `v`. R8 propagates the literal from `v` to `t_t1`.

### 4. Better finding messages

R8 shows the literal (truncated to 32 chars + "…") in the finding
message so AI dedup / human reviewers can see what the password
actually is:

```
Hard-coded password: DriverManager.getConnection called with
a literal string of length 8 as the password (literal: "7e5tc4s3")
```

vs. the R6 message which only said "literal string of length 8":

```
Hard-coded password: DriverManager.getConnection called with
a literal string of length 8 as the password
```
